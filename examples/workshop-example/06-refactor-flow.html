◆ Flow · The Inner Loop

One small refactor, start to finish

Repeat this loop once per smell. Never skip a step, never batch two.

👃
Step 1
Smell
Name one concrete problem — a long method, a duplicated block, a misleading name.
↓ pick the smallest safe move
🕸️
Step 2
Pin
Confirm the affected path already has a characterization test. If not, add one first.
↓ tests still green
✂️
Step 3
Extract
Make exactly one structural move — extract, rename, or inline. Nothing else.
↓ run the suite
◆
Step 4 · Gate
Verify
The whole suite runs. Green means behaviour held. This is the decision point.
↓ green only
💾
Step 5
Commit
A tiny, green, behaviour-preserving commit. A safe point to return to.
✓ Green at the gate Commit and loop back to Step 1 for the next smell.
✕ Red at the gate Revert the last single move — never debug forward — and retry smaller.
